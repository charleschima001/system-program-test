# Парсер товаров с сайта dental-first.ru
Вытаскивает названия товаров и их цены, а потом сохраняет всё в файлы `result_threaded.txt` и `result_async.txt`.

## Что нужно установить

Перед запуском нужно поставить четыре библиотеки:
- `requests` — чтобы скачивать веб-страницы
- `beautifulsoup4` — чтобы из HTML доставать данные
- `aiohttp` — для асинхронных запросов
- `Flask` — для тестового сервера (опционально)

### Для установки нужно ввести:
```bash
pip install requests beautifulsoup4 aiohttp Flask
```

## Как работает парсер товаров?
Многопоточная версия (thread_scraper.py):
1. Создаются 4 потока, каждый качает свою страницу
2. Каждый поток ищет блоки `.set-card.block` — это карточки товаров
3. Внутри ищется название (`a.di_b.c_b`) и цена (`.set-card__price`)
4. Всё собирается в один общий список
5. Итог записывается в файл `result_threaded.txt`
6. Также вычисляется общая стоимость всех товаров

Асинхронная версия (async_scraper.py):
1. Все 4 страницы скачиваются одновременно без создания потоков
2. Используется асинхронное программирование для параллельных запросов
3. Тот же алгоритм поиска товаров и цен
4. Результаты сохраняются в `result_async.txt`

### Запуск парсеров:
```bash
# Многопоточный парсер
python thread_scraper.py

# Асинхронный парсер  
python async_scraper.py
```

## Сравнение асинхронного и многопоточного сокет-серверов
Проект содержит два сервера — асинхронный и многопоточный, которые принимают соединения и возвращают количество строк в каждом файле в директории `test_files/`.
Также включён клиентский скрипт для тестирования скорости работы.

Файлы серверов:
- `socket_server_async.py` — асинхронный сервер на asyncio
- `socket_server_threaded.py` — многопоточный сервер
- `socket_client_test.py` — клиент + тест производительности

### Запуск сокет-серверов:
1. Запустите асинхронный сервер (в первом терминале):
```bash
python socket_server_async.py
```

2. Запустите многопоточный сервер (во втором терминале):
```bash
python socket_server_threaded.py
```

3. Запустите тестовый клиент (в третьем терминале):
```bash
python socket_client_test.py
```

Скрипт создаст тестовые файлы, подключится к обоим серверам и выведет сравнение времени работы.
